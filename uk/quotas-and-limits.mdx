---
title: "Квоти та ліміти"
description: "Ліміти Memory MCP, тарифні плани, вимоги до підписки та що враховується в квотах."
---

Memory MCP застосовує ліміти на виклики `retrieve_memory` для кожного акаунта. Ліміти залежать від тарифного плану.

MCP-виклики **не** списують кредити чату, але потрібна активна підписка із залишком кредитів.

## Що враховується

**Враховуються:** `tools/call` з `name: retrieve_memory` на `POST /v1/mcp/memory` — включно з заблокованими після автентифікації (quota exceeded, entitlement blocked тощо).

**Не враховуються:**

- `initialize`, `initialized`, `tools/list`, `resources/list`, `prompts/list`
- REST-виклики Developer API (`/v1/dev/*`)

## Ліміти за планами

| План | Тижневий ліміт | Місячний ліміт |
|------|----------------|----------------|
| Trial | 25 | 100 |
| Paid | 300 | 1 000 |
| Custom | 3 000 | 10 000 |

Усі плани також мають погодинний ліміт **100** запитів.

## Розклад скидання

| Вікно | Скидання |
|-------|----------|
| Погодинне | Початок кожної UTC години |
| Тижневе | Початок кожного UTC-тижня |
| Місячне | Початок кожного UTC-місяця |

## Перевірка підписки

`entitlement_required` повертається, коли на акаунті не залишилось кредитів. Оновіть або поновіть підписку PAM, щоб продовжити.

Memory MCP використовує кредити лише як перевірку активної підписки — окремі retrieval-виклики не зменшують баланс кредитів чату.

## Попередження про наближення до ліміту

Вкладка **Usage** на сторінці Memory MCP показує статус квоти:

| Статус | Значення |
|--------|----------|
| `ok` | У межах ліміту |
| `near_limit` | Понад 80% місячного ліміту |
| `limited` | Місячний ліміт досягнуто |
| `entitlement_required` | Немає активної підписки |

Актуальну квоту перевірте через `GET /v1/dev/mcp-config` — див. [Огляд API для розробників](/uk/developer-api-overview).

## Приклад: відповідь quota_exceeded

Помилка на рівні інструменту (HTTP 200, `isError: true`):

```json
{
  "content": [
    {
      "type": "text",
      "text": "Ви досягли тижневого ліміту Memory MCP. Спробуйте знову після понеділка 00:00 UTC або зменшіть частоту викликів retrieve_memory."
    }
  ],
  "structuredContent": {
    "status": "error",
    "error_code": "quota_exceeded",
    "error_message": "Ви досягли тижневого ліміту Memory MCP. Спробуйте знову після понеділка 00:00 UTC або зменшіть частоту викликів retrieve_memory."
  },
  "isError": true
}
```

## Історія запитів

Кожна спроба `retrieve_memory` зберігає повний prompt і відповідь для перегляду в **Memory MCP → Request history** та через `GET /v1/dev/mcp-requests`.

<Warning>
  `quota_exceeded` стосується лише `retrieve_memory` через `tools/call`, а не handshake-методів чи REST Developer API.
</Warning>
