Memory MCP дозволяє Claude Code, Cursor або вашому власному агенту отримувати контекст компанії з PAM — людей, проєкти, рішення, процеси, пріоритети, історію, клієнтів і внутрішню термінологію — без запису в історію чату та без списання кредитів чату за кожен виклик.

<Tip>
  Вперше з Memory MCP? Почніть із [Швидкого старту](/uk/quickstart): згенеруйте ключ, підключіть клієнт і виконайте перший виклик `retrieve_memory`.
</Tip>

## Що робить Memory MCP

- Надає окремий MCP-сервер на `POST /v1/mcp/memory` (JSON-RPC 2.0 через HTTP)
- Має один production-інструмент у v1: **`retrieve_memory`**
- Автентифікується статичним **`pam_mkey`** (desktop-агенти) або **OAuth 2.1** Bearer tokens (Claude web, ChatGPT)
- Зберігає журнал retrieval окремо від PAM Chat у застосунку
- Застосовує квоти на виклики retrieval для кожного акаунта

## Чого Memory MCP не робить

- Не записує в потоки PAM Chat і не змінює ваш workspace
- Не списує кредити чату за кожен MCP-виклик (лише перевірка активної підписки)
- Не надає доступ на запис до пам'яті чи інтеграцій

## Передумови

Перед підключенням MCP-клієнта:

1. Підключіть хоча б одне джерело пам'яті в PAM (Gmail, Drive, Notion, Slack або іншу підтримувану інтеграцію)
2. Дочекайтесь завершення початкової синхронізації та обробки пам'яті
3. Оберіть тип клієнта на **Memory MCP** — згенеруйте `pam_mkey` для desktop або скопіюйте MCP URL для браузерних LLM

<Note>
  Налаштування клієнта, ротація ключів і приклади конфігурації доступні на [сторінці Memory MCP](https://pam.harmix.ai/for-developers) у застосунку PAM.
</Note>
