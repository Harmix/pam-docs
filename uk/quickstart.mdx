Пройдіть від нуля до успішного виклику `retrieve_memory`. Оберіть шлях для вашого клієнта.

## Передумови

- Акаунт PAM із підключеним джерелом пам'яті
- Статус **Ready** у Memory MCP
- MCP-сумісний клієнт

## Desktop-агенти (Cursor, Claude Code, VS Code)

<Steps>
  <Step title="Згенеруйте API ключ агента">
    Відкрийте [Memory MCP](https://pam.harmix.ai/for-developers), оберіть **Desktop app or script** і натисніть **Generate key**.

    Скопіюйте повний ключ одразу — після виходу зі сторінки секрет більше не відображається. Формат ключа: `pam_mkey_<prefix>.<secret>`.
  </Step>
  <Step title="Додайте MCP-сервер у клієнт">
    Вставте цю конфігурацію в налаштування MCP-клієнта. Замініть placeholder на ваш повний ключ.

    ```json
    {
      "mcpServers": {
        "pam_memory": {
          "type": "http",
          "url": "https://api.pam.harmix.ai/v1/mcp/memory",
          "headers": {
            "Authorization": "pam_mkey_<prefix>.<secret>"
          }
        }
      }
    }
    ```

    Детальні інструкції для Cursor, Claude Code і VS Code — у розділі [Налаштування клієнта](/uk/client-setup).
  </Step>
  <Step title="Додайте інструкції для агента">
    Додайте цей фрагмент у системний промпт агента, щоб він знав, коли потрібно отримувати пам'ять:

    ```text
    You have access to PAM Memory through the retrieve_memory MCP tool.

    Use it when a request may depend on company-specific context:
    people, projects, decisions, processes, priorities, history, customers,
    documents, meetings, or internal terminology.

    Prefer retrieving memory before making assumptions.

    If retrieved context is partial or uncertain, say so and ask a focused follow-up.
    ```
  </Step>
  <Step title="Запустіть hello world prompt">
    Поставте агенту запитання:

    ```text
    Що ми знаємо про поточні пріоритети проєктів і хто відповідає за follow-up по кожному з них?
    ```

    Агент має викликати `retrieve_memory`. Успішний виклик позначає ключ як **MCP verified**.
  </Step>
</Steps>

## Браузерні конектори (ChatGPT, Claude web)

<Steps>
  <Step title="Скопіюйте MCP URL">
    У Memory MCP оберіть **Web browser LLM** і скопіюйте **MCP server URL**.
  </Step>
  <Step title="Додайте custom connector">
    У ChatGPT або Claude web додайте MCP-конектор і вставте URL. OAuth Client ID не потрібен — конектор реєструється через DCR автоматично.

    Деталі — у [Налаштуванні клієнта](/uk/client-setup) (вкладки `chatgpt.com` та `claude.ai`).
  </Step>
  <Step title="Підтвердіть доступ у PAM">
    Увійдіть у PAM і натисніть **Allow** (наприклад, *«chatgpt.com зможе читати вашу PAM memory»*). **Cancel** повертає вас без доступу.
  </Step>
  <Step title="Запустіть hello world prompt">
    Поставте те саме тестове запитання й перевірте **Request history** у Memory MCP.
  </Step>
</Steps>

<Check>
  Налаштування завершено, коли агент повертає контекст компанії після успішного виклику `retrieve_memory`.
</Check>
